Master Replica Blueprint & System Architecture Specification

1. Executive Summary

Foxe Studio Keuangan adalah sistem otomasi operasional keuangan, audit rekonsiliasi kasir, pelacakan pipeline jadwal foto, dan CRM penagihan prospek berbasis serverless single-page application (SPA). Arsitektur ini dirancang khusus untuk studio foto komersial dengan intensitas transaksi harian tinggi, fluktuasi musiman yang tajam (Super Peak Wisuda), serta pembagian peran kru shift dinamis.

Pilar Utama Nilai Sistem:
  • Biaya Infrastruktur Nol (Zero Hosting Cost): Berjalan penuh di atas GitHub Pages gratis, ditenagai file database statis foxe_full_state.json sebagai Single Source of Truth.
  • Sinkronisasi Cloud Otonom: Bekerja di background melalui GitHub Actions crons (08:30, 12:00, 15:00, 18:00, 21:00, 21:30 WIB) dan Railway worker tanpa perlu laptop studio menyala 24 jam.
  • Audit Kasir Zero-Guesswork: Memvalidasi rumus kasir Kas Tunai + Transfer Bank == Total Omzet secara otomatis dengan batas toleransi selisih maksimum Rp 1.000.
  • Pencegahan Ghost Slots: Memisahkan sesi reschedule (label Orange) agar sisa pelunasan tidak dihitung ganda, sekaligus menjaga masa aktif DP klien selama 30 hari di CRM.

B. Standar Desain Fit-In & Anti-Tabrakan (Rule 4)

  • Lebar Kontainer (.view): Wajib menggunakan max-width: 1600px; width: 100%; margin: 0 auto; padding: 28px 32px 80px;. Dilarang membatasi ke 1200px kaku agar tidak muncul ruang kosong.
  • Grid Adaptif: Menggunakan repeat(auto-fit, minmax(360px, 1fr)) dengan breakpoint di 1080px.
  • Scrollable Table: Seluruh tabel data panjang (Log Order, Detail Neraca, Leads, Jadwal) wajib dibungkus kontainer scrollable (max-height: 460px – 520px; overflow-y: auto;) dengan sticky table header (thead).

6. Product Requirement Document (PRD) Resmi

Tujuan Produk: Menyediakan sistem intelijen keuangan studio foto yang menyatukan rekonsiliasi kasir harian, penjadwalan multi-backdrop wisuda, manajemen honor kru, dan follow-up prospek tanpa ketergantungan pada server berbayar.

Fitur Inti & Spesifikasi:

  • FR-1 (Landing Laporan Tahunan): Menampilkan Seasonality Index 12 bulan (garis tengah 1.00×), tabel perbandingan tahunan, serta isolasi bulan non-aktif dengan badge Belum Dicocokkan.
  • FR-2 (Rekonsiliasi Kasir Dinamis): Mengaudit formula Omzet = Kas + Transfer dengan cut-off otomatis mengikuti hari transaksi terakhir.
  • FR-3 (Sandi Warna Jadwal): Menyaring slot 🟠 (Orange) dari sisa pelunasan agar tidak over-estimasi, namun mencatat masa tenggang DP 30 hari di CRM.
  • FR-4 (Neraca COGS & OPEX): Mengambil biaya murni dari kolom P s.d. U File Neraca, memisahkannya menjadi biaya pokok penjualan (COGS) dan operasional (OPEX), serta menampilkan Buku Detail Kas.
  • FR-5 (Roster Kru & Shift): Menghitung total shift kehadiran aktual fotografer dan asisten untuk estimasi beban upah shift.
  • FR-6 (CRM Leads & Analisis Permintaan): Melacak funnel MTD (Hot, Warm, Cold, Closed, Win Rate) dan memetakan paket paling diminati (Wisuda, Family, Large Group, Self Photo).
  • FR-7 (Struk Telegram Monospace): Mengirimkan struk kasir 44 kolom lengkap dengan rincian Unrealized Cash-In, DP (-), Total Pelunasan, dan Estimasi Omzet Akhir Bulan.

Formula Finansial Baku:

$$ ext{Omzet Realized (MTD)} = \sum ext{Kas Tunai} + \sum ext{Transfer Bank}$$

$$ ext{Unrealized Cash-In} = \sum_{ ext{Slot Hijau}} ext{Harga Paket Booking H+1 s.d. Akhir Bulan}$$

$$ ext{Sisa Pelunasan Riil} = ext{Unrealized Cash-In} - \sum_{ ext{Slot Hijau}} ext{DP Diterima}$$

$$ ext{Estimasi Omzet Akhir Bulan} = ext{Omzet Realized} + ext{Sisa Pelunasan Riil}$$

$$ ext{Estimasi Nett Profit} = ext{Omzet Realized} - ( ext{COGS} + ext{OPEX} + ext{Beban Payroll Kru})$$

7. Panduan Duplikasi & Setup Proyek

  1. Kloning Repositori: Buat repositori baru di GitHub dan clone ke komputer lokal.
  2. Pasang GitHub Secrets: Masukkan TELEGRAM_BOT_TOKEN dan TELEGRAM_CHAT_ID di menu Settings repositori.
  3. Hubungkan Google Drive: Buka core_engine/deep_sync_foxe.py dan perbarui daftar File ID sesuai spreadsheet studio baru Anda.
  4. Eksekusi Kompilasi Awal: 
    pip install -r config_and_secrets/requirements.txt
python core_engine/deep_sync_foxe.py
python core_engine/assemble_app.py
  5. Aktifkan GitHub Pages: Pilih branch main sebagai sumber deployment. Dashboard web Anda langsung aktif!
